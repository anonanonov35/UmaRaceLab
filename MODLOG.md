## Рабочий первый срез

- Python 3.11+ / Tk / SQLite, без внешних зависимостей приложения. Модули: models, data, conditions, engine, gui.
- UI: 1–18 билдов, пять статов, три пригодности, стратегия, настроение, навыки, сохранение уровня уникального навыка. Начальные билды вымышленные; выбор персонажа задаёт только его ID/имя.

- Базовая модель по явно атрибутированным community-формулам; независимые участники, без рельефа/полос/position keep/kakari. Ограничения изложены в UI и docs/ACCURACY.md.

- Проверены пауза/перемотка, штатный расчёт в фоновом потоке, отображение результатов, справочник и билды. Скриншоты окна: `local/ui-race.png`, `local/ui-builds.png`, `local/ui-skills.png`; снимки просмотрены.

- 21 проверка ядра пройдена: повторяемость, диапазоны, round-trip билдов, эффекты/условия, запрет неподдерживаемых навыков, финиш/телеметрия, интерполяция эталона, неизменность SQLite и обновление через WAL. Проверка GUI завершилась без callback errors.
- SHA256 файла master.mdb до и после проверки совпал. Публикаций, установки мод-загрузчиков и изменений игры не выполнялось.
