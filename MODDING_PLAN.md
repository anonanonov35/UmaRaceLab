- Путь: `D:/SteamLibrary/steamapps/common/UmamusumePrettyDerby`.
- Steam App ID **3224770**, build ID **25384634**, язык манифеста `english`: исследуется Global-установка пользователя.
- Unity **2022.3.62f2**, IL2CPP, Windows x64. Стандартная сигнатура метаданных; версия заголовка **31**. Cpp2IL уточняет вариант формата **31.1**.

- Наблюдаемые таблицы: `skill_data` — **734** записи, `race_course_set` — **121**, `chara_data` — **96**, `card_data` — **111**.
- `text_data`: категория 6 — имена персонажей, 35 — названия ипподромов, 47 — имена навыков, 48 — описания навыков. Категории сверены с локальными записями.
- Логи Unity: `%USERPROFILE%/AppData/LocalLow/Cygames/Umamusume/Player.log`.
- Игра — сетевой сервис. Наличие или отсутствие конкретного античита статической проверкой не установлено. Проект не требует вмешательства в клиент.
- Местоположение аккаунтных сохранений не исследовалось: они не нужны для независимого приложения.

## Выбранный маршрут

Отдельная реализация + чтение пользовательской SQLite только в режиме `mode=ro` и `query_only=ON`. Это даёт актуальные параметры справочника без загрузчика, модификации клиента, сетевых запросов к серверам игры или привязки к аккаунту. Обновление данных не означает автоматическое обновление формул нативного кода.

Лаборатория декомпиляции: `%TEMP%/uma-race-lab-build25384634`. Локальные отчёты и экспорты — `local/`, инструменты — `.local/`; обе папки исключены из Git. Сохранения и настройки игры не меняются, резервная копия для такой операции не требуется.

## Проверенные инструменты и результат

1. [Il2CppDumper v6.7.46](https://github.com/Perfare/Il2CppDumper/releases/tag/v6.7.46), официальный net6-релиз. Прочитал metadata v31, но не нашёл `CodeRegistration`/`MetadataRegistration`. Его резервный PE-loader завершился Win32 error 126. Повторно этот loader не запускался; причина нулевых регистраций пока не установлена.
2. [Cpp2IL 2022.1.0-pre-release.21](https://github.com/SamboyCoding/Cpp2IL/releases/tag/2022.1.0-pre-release.21), официальный Windows x64-релиз. Прочитал metadata v31.1; статический поиск завершился `No codegen modules found for mscorlib`, адреса регистраций не найдены. Выгрузки тел методов не получено.
3. Собственный ограниченный парсер стандартной metadata v31 (`tools/inspect_metadata.py`) успешно проверил границы таблиц, строки и диапазоны полей/методов. Всего **38 646 типов**, **254 313 методов**, первоначальная выборка **2 104 типов**, связанных с race/skill. Это карта символов, а не декомпилированные тела.

Точные URL и SHA256 загрузок сохранены в `.local/*/provenance.json`; игровые файлы не копировались в инструментарий.

## Найденные точки для следующего этапа

- `Gallop.HorseRaceAISimulate`: создание калькуляторов position keep, temptation, целевой полосы и базовой скорости; обновление last spurt.
- `Gallop.HorseRaceInfoSimulate`: расход HP, обновление расстояния, блокировок, обгона и расчёт финишного времени.
- `Gallop.RaceManagerSimulate`: цикл симуляции, генератор случайных чисел, запись кадров и событий.
- `Gallop.RaceSimulator`: `LoadAndSimulate`, `Simulate`.
- `Gallop.RaceSimulateHorseFrameData`: `Distance`, `LanePosition`, `Speed`, `Hp`, `TemptationMode`, `BlockFrontHorseIndex`, `SpeedAccuracy`, `LaneAccuracy`.

Имена выше прочитаны из локальных метаданных. Их наличие не доказывает конкретную формулу, частоту шага или возможность вызвать симулятор вне клиента.

## Очерёдность

1. **Выполнено:** карта установки, схема базы, чтение справочника, карта гоночных символов, рабочий UI и экспериментальный прогон.
2. **Следующее:** статически разобраться с отсутствующими регистрациями и идентифицировать нативные тела расчётных функций. Сначала базовая скорость, ускорение, HP, шаг и порядок обновления. Не подменять этот результат предположением об обфускации.
3. Получить законно доступную пользователю эталонную запись/повтор с известными билдом и условиями; извлечь кадры в документированный JSON. Прямой доступ к аккаунту/серверу для этого не реализован.
4. Сравнить кадры: скорость, положение, HP и финиш, затем определить float32/float64, RNG и задержку применения действия. Записать MAE/RMSE и максимальные ошибки.
5. Расширять модель по одному проверенному механизму: рельеф → взаимодействия и полосы → язык условий → уникальные эффекты и уровни.
6. Отдельно версионировать правила Global, если версия игры отличается от community-источников. Полные требования завершённого продукта — в `docs/ROADMAP.md`.
